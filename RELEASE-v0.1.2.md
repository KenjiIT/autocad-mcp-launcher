Version 0.1.2:

- Added a Settings page option to start AutoCAD MCP Launcher when you sign in to Windows.
- Added skill installation and update for selected AutoCAD skills in Codex or Claude Code user skill folders.
- Kept Codex, Claude Code, and Claude Desktop in the MCP agent selector, with configuration output for each.

Known limitations:

- Skill installation is available for Codex and Claude Code. Claude Desktop skills still need to be imported through Claude Desktop.
- The launcher setup executable is not code-signed, so Windows SmartScreen may show an unknown publisher warning.
